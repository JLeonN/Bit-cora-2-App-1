## Pendientes

### Dificultad 4/10

- **Permitir omitir y volver a abrir el modal de actualización:** Agregar al modal una casilla para que el usuario pueda dejar de verlo durante la versión disponible actual, sin ocultar la notificación de actualización del menú de las tres líneas. Incorporar también una opción en Configuración, o en otro lugar accesible, para abrir nuevamente el modal de forma manual. Guardar la omisión por versión para que una actualización futura vuelva a mostrarse automáticamente.

### Dificultad 3/10

- **Mostrar feedback al agregar un ítem al listado:** Al confirmar un código escrito o seleccionar una sugerencia del autocompletado, mostrar una animación breve y visible que indique que el ítem se agregó correctamente. El feedback debe percibirse desde el área donde se ingresa el código, aunque el usuario no esté mirando la lista, sin interrumpir la carga de otros ítems ni mostrarse si la incorporación falla.

### Dificultad 2/10

- **Configurar App Check en GitHub Pages:** Cargar `FIREBASE_APP_CHECK_SITE_KEY` como variable del repositorio en GitHub Actions, usando la misma clave pública de reCAPTCHA Enterprise guardada localmente, y verificar que el despliegue la reciba correctamente.
